# 졸업 논문: Otsu Mask와 Salient Region 기반 입력 특징 추출과 ACGPN 모델 구조 확장을 통한 VTON 이미지 품질 비교
>가상 피팅(Virtual Try-On, VTON) 기술은 사용자의 전신 이미지에 의류를 자연스럽게 합성함으로써 비대면 환경에서도 실제 착용에 가까운 경험을 제공할 수 있다는 점에서 그 중요성이 커지고 있다. 그러나 기존의 VTON 기술은 입력 데이터의 전처리 방식에 따라 결과 이미지의 품질이 크게 달라지는 한계를 지닌다. <br>
본 논문에서는 가상 피팅 모델인 ACGPN의 입력 특징 추출 방식으로서 Otsu Mask와 Salient Region 기반 방식을 사용하였고, ACGPN의 입력 정보를 확장한 새로운 모델에 Salient Region 기반 입력 데이터를 활용하여 도출된 결과를 비교 분석하였다. 본 연구는 효과적인 입력 특징 설계뿐만 아니라, 구조적 개선을 통한 VTON 이미지 품질 향상 가능성을 제시함으로써 향후 기술 발전에 기여하고자 한다.
